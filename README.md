# Интеграция PastVu и Kontiki Maps

Небольшой прототип и исследовательские заметки о том, как связать данные о возрасте зданий из Kontiki Maps с историческими фотографиями PastVu.

## Цель

Сделать минимальный рабочий прототип: выбрать исторический период на карте старой Москвы, открыть здание в Яндекс Картах и найти ближайшие фотографии PastVu. Затем описать процесс как кейс для портфолио технического писателя.

## Демо

Прототип опубликован на GitHub Pages:

```text
https://thankfulfor.github.io/pastvu-kontiki-integration/
```

## Пользовательский сценарий

Пользователь выбирает период строительства, кликает по цветному зданию на карте и получает:

- адрес и год здания из Kontiki Maps;
- ссылку на выбранное место в Яндекс Картах;
- ближайшие фотографии PastVu;
- ссылки на исходные страницы фотографий PastVu.

## Что показывает прототип

В интерфейсе используются только поля, которые нужны для первого сценария:

| Источник | Поля | Зачем нужны |
| --- | --- | --- |
| Kontiki Maps | `r_name`, `r_adress`, `r_year_int`, `r_years_str`, `r_floors` | название, адрес, год, этажность и фильтр по годам |
| Kontiki Maps | геометрия `MultiPolygon` | контур кликабельного здания на карте |
| PastVu | `cid`, `file`, `title`, `year`, `year2`, `geo` | превью, год, ссылка на фото и маркер на карте |

Остальные поля fixture пока не выводятся: они не нужны для проверки основного сценария и могут усложнить интерфейс.

## Текущий статус

Добавлена статическая страница с картой. Она показывает выборку Kontiki Maps по старой Москве за 1357—2021 годы, фильтрует здания по годам, строит ссылку на Яндекс Карты и запрашивает ближайшие фотографии PastVu.

## Ограничения прототипа

- Используется выборка по старой Москве, а не полный набор городов Kontiki Maps.
- Данные разбиты на GeoJSON-файлы по периодам шкалы. Самые тяжёлые периоды весят десятки мегабайт, поэтому при дальнейшем росте данных может понадобиться нарезка по районам, bbox или переход на векторные тайлы.
- Центр полигона используется как приближённая точка здания для ссылок и поиска фотографий.
- Фотографии PastVu загружаются напрямую из публичного API без backend-прокси.
- Яндекс Карты открываются внешней ссылкой; API Яндекс Карт в первой версии не используется.
- Лицензию кода проекта и лицензию производных данных Kontiki нужно описывать отдельно.

## Локальный запуск

Запустите простой локальный сервер из корня репозитория:

```bash
python3 -m http.server 8080
```

Затем откройте:

```text
http://localhost:8080/
```
